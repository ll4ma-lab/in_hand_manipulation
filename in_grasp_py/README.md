# in_grasp_py

A ROS-free Python 3 interface to the relaxed-rigidity in-grasp manipulation planner (`../in_grasp_manipulation`), plus viser demos.

**Status:** skeleton only (milestone M0). See [../MIGRATION.md](../MIGRATION.md) for the roadmap, the architecture and what each milestone adds.

```bash
conda env create -f environment.yml   # env "ihm" (resolved in M2)
conda activate ihm
pytest
```
